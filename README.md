# MONO FISHING

白黒の釣りゲーム。追加ライブラリ不要、Node.js 20以上で起動します。

## 起動

このフォルダで `node server.mjs` を実行し、ブラウザーで http://localhost:3210 を開きます。Windowsでは `start.ps1` でも起動できます。ポートを変える場合は PowerShell で `$env:PORT=3211` を設定して起動してください。

## 遊び方

- 名前と合言葉を入力して入場。同じ合言葉・同じ釣り場のプレイヤーが一緒に表示されます。
- 池の岸をクリックすると移動。「釣り糸を投げる」を押し、「食いついた！」の表示から3.5秒以内に引き上げます。
- 森の池34種・海33種・川33種、計100種類の水辺の生き物（イカ・タコ・エビ・カニも含む）。釣果には画像、cm、獲得ポイントが表示されます。
- 図鑑で発見履歴を確認。ショップで頭・服・靴・水槽装飾を購入し、所持品をクリックすると装備できます。水槽装飾は再クリックで取り外せます。
- 水槽は釣果をクリックして最大24匹まで選択。requestAnimationFrameで描画し、時間差分を使った速度・方向変化で泳ぎます。60Hz画面では60fpsを目標に動作します（端末性能・画面のリフレッシュレートに依存）。
- コメントは最大60文字、頭上に6秒間表示されます。

## マルチプレイ

同じPCでは別のブラウザーまたは別プロファイルで開きます。同じブラウザープロファイルの複数タブは同じプレイヤーです。同一LANの別端末では `http://サーバーPCのLANアドレス:3210` を開き、同じ合言葉を入力します。OSのネットワーク設定によっては接続が許可されない場合があります。ファイアウォール設定は自動変更しません。

これはローカル/LAN用です。インターネットへの公開サーバー配備は未実施です。

## 保存

ポイント・釣果・購入済みスキン・装備は `save/players.json` に保存。ブラウザーのローカルストレージに保存したトークンで再入場します。ブラウザーデータを消すと同じプレイヤーに戻れません。水槽の魚の選択はブラウザーごとに保存されます。保存ファイルには再入場用トークンが含まれるため共有しないでください。

## 描画と仕様

魚は実物写真を参考にしたCanvas描画です。体形、背腹のグラデーション、鱗・斑点・帯模様・ヒレの光沢を31の体形グループと魚種ごとの差分で描き分けています。参考は `REFERENCES.md` に記録しています。実写素材や3Dではありません。魚のサイズと出現率はゲーム向けの設定です。

魚と釣り堀の自然物だけカラー。UI、アバター、水槽装飾は白黒です。未発見の図鑑は詳細画面も黒塗りのシルエット。図鑑は最大サイズ順に並び、小型で一般的な種から大型のレジェンドへ進みます。既存の魚IDと釣果はそのまま引き継ぎます。

水槽装飾は13種類、60〜1,000,000ポイント。最も高いものは「海底宮殿アトランティス」です。石・水草・流木・貝殻・洞窟・石柱・沈没船などを選べます。

名前が「かいはつ」の場合だけ、全アイテムをポイント消費なしで購入できます。右上の名前をクリックすると、進行状況を保ったまま名前と合言葉を変更できます。無料購入の判定はサーバーに保存された名前で行います。「かいはつさん」など別の名前は通常価格です。

外部のグラフィックツールや素材のダウンロードは行っていません。

`node --test test.mjs` で通信・釣果・購入・データの確認を実行できます。
